Project Title: Smart City Infrastructure Simulation
Team Size: 2
Course: Computer Networks

Project Description:
Designed and simulated a Smart City Infrastructure using Cisco Packet Tracer as part of the Computer Networks course. The project demonstrated the integration of various smart devices and network components, including traffic lights, IoT sensors, smart homes, and communication systems. Focused on implementing network topologies, IP addressing, routing protocols, and device configurations to create a fully connected city environment. The project highlighted practical knowledge of networking principles, device interoperability, and the role of networks in smart urban development.
